# CSV/TSV JSON 변경 계획 — 사용자 승인형 배치 편집

ToolBox는 JSON 셀 변경 계획을 **텍스트로 붙여넣기 → 검증 → 전체 미리보기 → 명시적 승인 → 메모리 적용 → 별도 저장** 순서로 처리한다. 외부 AI 계정 로그인·MCP 네트워크·원격 파일 접근은 아직 구현되지 않았다.

- 원본 CSV/TSV의 SHA-256 확인값을 계획에 명시한다.
- 현재 표에서 예상 셀 값이 다르면 전체 계획을 거부한다.
- 동일 셀 중복 변경, 범위 밖 좌표, 변경 전후 동일한 값, 허용되지 않는 JSON 필드, 최대 크기 초과를 거부한다.
- 미리보기 이후 표의 어느 셀이라도 바뀌면 승인 시 전체 계획을 거부한다.
- 승인 시 여러 셀을 **한 번의 Undo 단계**로 적용한다. 디스크 파일은 저장 버튼을 누르기 전까지 변경되지 않는다.
- 승인 후 기존 CSV 복구 스냅샷에도 변경 내용을 기록한다. 저장은 기존 백업·외부 변경 감지 정책을 따른다.
- 계획의 유효성은 사용자가 명시적으로 붙여넣은 CSV 문서 하나에만 적용된다. 명령 실행, 파일 삭제, 네트워크 송신, 다른 문서 변경을 수행할 수 없다.

형식은 [CSV_EDIT_PLAN_SCHEMA.md](CSV_EDIT_PLAN_SCHEMA.md)를 참고한다. 이 기능은 미래의 AI 작업 게이트웨이를 위한 안전한 **로컬 작업 승인 구조**이며, 현재 ChatGPT나 Codex를 실제 연결한 기능은 아니다.
